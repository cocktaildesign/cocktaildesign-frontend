# «О нас»: локальный макет мастерской

10.11.2026. Страница подготовлена **только локально**. Публикация, push, PR,
изменения CMS и рабочего сайта не входят в эту задачу.

## Где менять

- Страница: `src/app/about/page.tsx`.
- Все фотографии, видео, хронология и публикации: `src/app/about/about-content.ts`.
- Только локальные стили страницы: `src/app/about/AboutPage.module.css`.
- Изображения: `public/images/about/`.

Шапка, подвал, навигация, каталог, корзина и API не изменены. Страница использует
общий PageLayout. Старую сетку категорий убрали: история компании больше не
запрашивает каталог ради товарных счётчиков.

## Медиа и замена

| Место | Сейчас | Рекомендуемая замена |
|---|---|---|
| `hero` | AI-иллюстрация, видимая подпись о макете | Реальные руки, процесс или собственное изделие. 4:3, 1440×1080 px |
| `workshop` | AI-иллюстрация стола мастерской | Реальное производство. 1440–1920 px по ширине, важное в центральной части кадра |
| `founder` | Оригинальный архивный портрет Inshaker | Собственный портрет либо подтверждённое разрешение на этот снимок |
| `earlyTool` | Оригинальная фотография инструментов Inshaker | Собственный архивный снимок либо подтверждённое разрешение |
| `team` | Аккуратная подписанная заглушка, `null` | Настоящая команда, горизонтальный кадр. На телефоне кадрирование 4:3 |
| `video` | `null`, обычное фото без ложной кнопки Play | Реальное видео производства; необязательно для выпуска страницы |

Для изображения укажите `src`, ширину, высоту, осмысленный `alt` и подпись.
Если есть варианты 640/960/1440 px, обновите `srcSet` с их фактическими ширинами.
В этой версии оптимизация Next Image в проекте отключена, поэтому используются
заранее уменьшенные WebP и нативный `srcset`. Не кладите оригинал в несколько
мегабайт вместо маленького файла.

Рабочий ориентир: 50–180 КБ на крупное фото после проверки качества, меньше для
мобильной версии. Это ориентир, а не причина портить детали металла компрессией.
Не вытягивать фото и не обрезать руки/инструменты ради пропорции.

После реальной замены выставить `isDemo: false`, `requiresReplacement: false`,
а `publicationApproved: true` — только после проверки содержания и права
использования. Эти флаги фиксируют статус; они не являются механизмом деплоя.
Нельзя просто скрыть подпись «Иллюстрация» у оставшегося AI-изображения.

Для команды вместо `null` задаётся такой же объект фотографии. Никакой новой
вёрстки для этого не требуется. Заглушка автоматически заменится фотографией.

## Видео

В `aboutMedia.video` можно задать:

```ts
{ src: "/videos/about/workshop.webm", title: "Как мы создаём инструменты", captionsSrc: "/videos/about/workshop.ru.vtt" }
```

Используется нативный доступный плеер: `controls`, `preload="none"`, `playsInline`,
без автозапуска и без внешнего iframe. `captionsSrc` нужен, если есть речь.
Постер берётся из `aboutMedia.workshop.src`. Название должно описывать реальный
процесс: ролик про клише не подписывается как изготовление стрейнеров.
Воспроизведение реального ролика в этой задаче не проверялось: его пока нет.

Это оригиналы, не вырезки из AI-макета. Подписи сохраняют архивный контекст.
Разрешение на публичное повторное использование не подтверждено; пока только
локальный предпросмотр. Фото инструментов 2019 года не названо первой моделью 2016 года.

Hero и мастерская созданы встроенным image_gen специально как временные
иллюстрации. Это не настоящие сотрудники, помещения или конкретные модели CD.
Точные промпты, оригиналы, размеры и хеши находятся в handover workspace:
`audit/about-page-20261110/assets/prompts.md`, `image-manifest.json`, `sources.md`.

## Редакционные решения

- Сразу обозначены и собственное производство, и товары других брендов.
- Сохранены 2015/2016 из брифа владельца; точный день запуска и цифра стажа
  барменом не добавлены как независимо проверенные факты.
- Награды 2017/2019 сформулированы по номинациям и связаны с источниками.
- WHERE2DRINK подписан партнёрским материалом; подкаст — архивом, Telegram — анонсом.
- Вместо неподтверждённых условий пожизненной гарантии — помощь и контакты.
  Обещание гарантии можно добавить после согласования покрытия и исключений.
- SEO: тот же `/about`, общий canonical/robots, один H1, обычный HTML,
  связанная разметка OnlineStore/AboutPage/BreadcrumbList. Фото-заглушки не
  добавлены в разметку организации или Open Graph как документальные материалы.
